MP3 → SRT
=========

1. Otevřete index.html v aktuálním prohlížeči Edge nebo Chrome.
2. Vyberte MP3.
3. Pro slovenštinu ponechte jazyk „Slovenština“ a model „Base“.
4. Klikněte na „Vytvořit titulky“.
5. Po dokončení stáhněte SRT nebo TXT.

Důležité:
- MP3 zůstává v počítači. Stahuje se pouze knihovna Transformers.js a model Whisper.
- První spuštění vyžaduje internet a stažení modelu.
- Pro delší podcast může být potřeba více operační paměti.
- WebGPU je obvykle rychlejší. Když nefunguje, zvolte výpočet WASM.
- Nejlépe funguje, když je soubor umístěn na webu (např. GitHub Pages). Ve většině aktuálních prohlížečů však lze index.html otevřít i přímo.
